Подключение реального времени

Для работы через телефоны участников нужна бесплатная база Firebase Realtime Database и включённый анонимный вход. Вставьте JSON-конфигурацию веб-приложения, затем создайте комнату. Полная инструкция и правила безопасности включены в архив.

Важно: для использования QR входа опубликуйте страницу по HTTPS (например, GitHub Pages). При открытии файла с диска телефоны не смогут открыть ваш локальный адрес.
