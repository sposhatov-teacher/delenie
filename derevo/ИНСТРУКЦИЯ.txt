ДЕРЕВО МОИХ ДОСТИЖЕНИЙ — ОНЛАЙН
Автор Пошатов С.Г.

Состав: index.html — учитель, student.html — ученики.
Файлы используют уже существующий Firebase-проект delenie-real.

1. Загрузите папку derevo в репозиторий GitHub Pages (в существующем репозитории delenie).
2. Откройте https://sposhatov-teacher.github.io/delenie/derevo/ (после публикации).
3. На учительской странице появится QR на student.html?room=...
4. Ученик сканирует QR, вводит имя и выбирает цвет листа.
5. Листья появляются у учителя в реальном времени.
6. Новый урок создаёт новую комнату и QR.

ВАЖНО: требуется настроить правила Firebase Realtime Database для ветки reflectionTree/v1/sessions. Без соответствующих правил запись учеников будет запрещена. Не применяйте открытые правила ко всей базе: лучше ограничить доступ к ветке, предусмотреть аутентификацию учителя, защиту от спама и автоматическое удаление старых данных. Для пилота используйте тестовую базу без персональных данных учащихся. QR работает только после размещения страниц по публичному HTTPS-адресу.
